# Intel Tools Directory (AX Global)

Static, searchable directory of OSINT, threat-intel, OPSEC and security-training tools. No framework, no dependencies beyond Python 3.

## Files
- `data/raw.txt` – the single source of truth: `name|url|category|Free/Paid|expert note` (one tool per line).
- `data/tools.json` – generated by `check_urls.py` from raw.txt, containing only URLs that resolved.
- `data/featured.txt` – names of paying featured-listing customers (one per line). They are pinned and highlighted.
- `build.py` – generates `dist/` (home, one page per category, /advertise/, /submit/, /subscribe/, sitemap.xml, robots.txt, style.css).
- `refresh.sh` – daily routine: re-check every URL, drop dead ones, rebuild.

## Rebuild
    ./refresh.sh                  # check URLs + build
    python3 build.py              # build only
    python3 -m http.server -d dist 8001   # preview at http://localhost:8001

## Build-time overrides (env vars)
SITE_NAME, SITE_URL (e.g. https://your-domain.com), SQUARE_LINK_FEATURED ($49/mo), SQUARE_LINK_BANNER ($199/mo),
SQUARE_LINK_EMAIL ($99), CONTACT_EMAIL, SUBSCRIBE_FORM_ACTION (newsletter signup endpoint, e.g. Constant Contact/Resend form).

    SITE_NAME="OSINT Toolbox" SITE_URL=https://your-domain.com SQUARE_LINK_FEATURED=https://square.link/u/... ... python3 build.py

## Deploy
Upload `dist/` to any static host (Vercel/Netlify/GitHub Pages/Cloudflare Pages). On Vercel: framework "Other",
build command `python3 build.py`, output directory `dist`.

## Config
Contact email and Square links live in config.py (env vars of the same name override).
